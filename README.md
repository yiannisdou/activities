# activities

Φύλλα Εργασίας, Προσομοιώσεις και εκπαιδευτικά εργαλεία για τα μαθήματα Α΄, Β΄, Γ΄ τάξης ΕΠΑΛ, του Τομέ Ηλεκτρολογίας, Ηλεκτρονικής και Αθτοματισμού.

Άδεια χρήσης
Το υλικό αυτό δημιουργήθηκε για να βοηθήσει μαθητές και εκπαιδευτικούς των ΕΠΑΛ και μπορείτε να το χρησιμοποιήσετε ελεύθερα για μη εμπορικούς σκοπούς.

Κώδικας (HTML, CSS, JavaScript, sketches Arduino): άδεια MIT
Εκπαιδευτικό υλικό (φύλλα εργασίας, φυλλάδια, κείμενα, εικόνες): άδεια CC BY-NC-SA 4.0
Quiz και προσομοιώσεις σε HTML: ο κώδικας με άδεια MIT, οι ερωτήσεις, οι επεξηγήσεις και τα κείμενα με άδεια CC BY-NC-SA 4.0
